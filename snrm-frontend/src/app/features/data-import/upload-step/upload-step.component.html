What the files should contain
Sheet / file Required columns Notes
network_meta period_length_value, period_length_unit, horizon_periods Optional. Absent means 1 day / 52 periods / NEAREST, which you are asked to confirm.
nodes name, type type is SUPPLIER, PLANT, DC or CUSTOMER. Names are unique within the file.
links source, target Both reference nodes.name. Self-loops and duplicate pairs are rejected.
products name Optional; a default product is created if absent.
node_products node, product demand_value applies to CUSTOMER nodes; inventory fields to supply-side nodes.

Any *_unit column may be omitted, in which case the value is read in the network's period unit - so a plain numeric file works unchanged. Unit tokens are case-insensitive and accept abbreviations (h, hr, hrs, hour, hours). Column names that do not match are yours to map in the next step. nodes also takes pos_x/pos_y, the canvas coordinates, so an exported layout comes back as it was.

An XML document carries all of this in one self-describing file and names its own fields, so it needs no column mapping - the wizard goes straight to validation. It is the format to keep a network in.

Several workbooks at once (FR-28). Drop two or more .xlsx files and each becomes its own network, named after its file. One mapping and one time base apply to the whole batch - files imported together are files of one shape, so import heterogeneous files one at a time. A batch is workbooks and nothing else: mixing them with CSV files, or dropping several XML documents, is refused rather than guessed at.
